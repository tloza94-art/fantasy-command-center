# Fantasy Command Center PWA

Personal installable Sleeper fantasy-football dashboard.

Included now:
- Username switcher
- 2026 Sleeper leagues
- Starter / Bench / IR / Taxi
- Injury dashboard
- Multi-league injury exposure
- Team viewer
- Player search
- Exposure ranking
- Installable PWA shell

## Local test
From this folder:
`python3 -m http.server 8080`
Then open `http://localhost:8080`

## Install on iPhone
Host over HTTPS, open in Safari, Share -> Add to Home Screen.

## Hosting
GitHub Pages, Netlify, Cloudflare Pages, or Vercel will work.

This personal prototype calls Sleeper's public read-only API directly.
